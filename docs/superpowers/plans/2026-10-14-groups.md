# Groups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Facebook-style Groups: public and private groups with admin/moderator/member roles, join requests, a group post stream that also appears in members' main feed.

**Architecture:** A `Group` table plus `GroupMember` and `GroupJoinRequest` join tables; `Post` gains a nullable `groupId`, so group posts reuse reactions, comments, images and `/p/[id]` unchanged. One pure function `canViewPost` decides visibility for every post (group rule or friends rule), and one pure `permissions.ts` encodes the role matrix. New `src/features/groups/` folder mirrors `src/features/friends/` (schemas, queries, actions, components); new pages live under `src/app/(app)/groups/` and `src/app/(app)/g/[slug]/`.

**Tech Stack:** Next.js 16 App Router (server components + server actions), TypeScript, Prisma 7 + PostgreSQL, zod 4, Tailwind, Vitest (pure units), Playwright (e2e, serial, against `pnpm dev`).

**Spec:** `docs/superpowers/specs/2026-10-14-groups-design.md`

## Global Constraints

- Follow `AGENTS.md`: this Next.js version differs from training data; read `node_modules/next/dist/docs/` when unsure. Pages type their props with the global `PageProps<'/route'>` helper (generated by `next dev` / `next typegen`).
- Group name: 1–80 chars after trim. Description: ≤500 chars, empty stored as `null`. Slug: ≤60 chars, lower-case, `[a-z0-9-]`, unique, never changes after creation.
- Roles: exactly `ADMIN`, `MODERATOR`, `MEMBER`. Privacy: exactly `PUBLIC`, `PRIVATE`.
- Server actions return `ActionResult` from `src/lib/action-result.ts`; permission failures return `fail('...')`, never throw.
- All group-affecting actions revalidate with `revalidatePath('/', 'layout')` (same as friends), because membership changes the feed, group pages, the groups index and the post cards.
- After any `prisma migrate dev` / `prisma generate`, the running `next dev` server must be restarted (kill the node process on port 3000, run `pnpm dev` again), or pages fail with `PrismaClientValidationError: Unknown field`.
- Playwright runs with one worker against the dev server; the first run after a code change is slow (Turbopack cold compile). Do not shorten timeouts.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Do not commit `prisma/schema.sql` (untracked scratch file already in the tree).

## Review Focus

1. A group name that normalises to an empty slug (e.g. `"!!!"` or a non-Latin name) must still create a group with a usable URL; test in Task 3 (`slugify` falls back to `group`).
2. A member who opens a group page, is then removed by an admin, and submits the stale composer must get "You must be a member to post here", not a post; test in Task 9 e2e.
3. A non-member must not reach a private group's post through its `/p/[id]` URL (reactions and comments route through the same check); test in Task 2 (`canViewPost`) and Task 9 e2e (404).
4. Switching a private group to public must not strand pending requests; they become members in the same transaction; test in Task 9 e2e.
5. An admin must not be able to demote or remove themselves, and the last admin must not be able to leave, so a group can never be left without an admin; test in Task 3 (`permissions`) and Task 9 e2e (last admin cannot leave).

```ts
export type GroupPrivacy = 'PUBLIC' | 'PRIVATE'

export type PostVisibilityInput = {
  authorId: string
  group: { id: string; privacy: GroupPrivacy } | null
}

/**
 * Whether `viewerId` may see a post. A group post is visible when the group is
 * public or the viewer is a member; a post outside a group follows the friends rule.
 */
export function canViewPost(
  viewerId: string,
  post: PostVisibilityInput,
  friendIds: readonly string[],
  memberGroupIds: readonly string[],
): boolean {
  if (post.group) {
    return (
      post.group.privacy === 'PUBLIC' || memberGroupIds.includes(post.group.id)
    )
  }
  return canViewPostsOf(viewerId, post.authorId, friendIds)
}
```

```ts
/** URL slugs for groups: lower-case ASCII words joined by dashes, never empty. */

export const SLUG_MAX = 60
const SUFFIX_LENGTH = 4

export function slugify(name: string): string {
  const base = name
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
    .slice(0, SLUG_MAX)
    .replace(/-+$/g, '')
  return base || 'group'
}

/** `slug-xxxx` with four random base36 characters, trimmed so it still fits SLUG_MAX. */
export function withSuffix(slug: string): string {
  const suffix = Array.from({ length: SUFFIX_LENGTH }, () =>
    Math.floor(Math.random() * 36).toString(36),
  ).join('')
  const head = slug
    .slice(0, SLUG_MAX - SUFFIX_LENGTH - 1)
    .replace(/-+$/g, '')
  return `${head}-${suffix}`
}
```

```ts
/** Group role matrix; pure so it can be unit-tested and shared by server and client code. */

export const GROUP_ROLES = ['ADMIN', 'MODERATOR', 'MEMBER'] as const
export type GroupRole = (typeof GROUP_ROLES)[number]

export function isGroupRole(value: unknown): value is GroupRole {
  return (GROUP_ROLES as readonly unknown[]).includes(value)
}

/** Moderators and admins: delete any post, remove plain members. */
export function canModerate(role: GroupRole | null): boolean {
  return role === 'ADMIN' || role === 'MODERATOR'
}

/** Admins only: settings, roles, join requests, deleting the group. */
export function canManage(role: GroupRole | null): boolean {
  return role === 'ADMIN'
}

export function canDeleteGroupPost(
  viewerId: string,
  postAuthorId: string,
  viewerRole: GroupRole | null,
): boolean {
  return viewerId === postAuthorId || canModerate(viewerRole)
}

type Actor = { id: string; role: GroupRole }

export function canRemoveMember(actor: Actor, target: Actor): boolean {
  if (actor.id === target.id) return false
  if (actor.role === 'ADMIN') return true
  return actor.role === 'MODERATOR' && target.role === 'MEMBER'
}

export function canChangeRole(actor: Actor, targetId: string): boolean {
  return actor.role === 'ADMIN' && actor.id !== targetId
}

/** The last admin must promote someone before leaving. */
export function canLeave(role: GroupRole, adminCount: number): boolean {
  return role !== 'ADMIN' || adminCount > 1
}
```

```ts
import { prisma } from '@/lib/db'
import type { GroupPrivacy } from '@/lib/feed'
import { personSelect, type Person } from '@/features/friends/queries'
import type { GroupRole } from './permissions'

export const groupSelect = {
  id: true,
  slug: true,
  name: true,
  description: true,
  privacy: true,
  _count: { select: { members: true } },
} as const

export type GroupSummary = {
  id: string
  slug: string
  name: string
  description: string | null
  privacy: GroupPrivacy
  memberCount: number
}

export type GroupView = GroupSummary & {
  viewerRole: GroupRole | null
  requested: boolean
}

export type Member = { user: Person; role: GroupRole; joinedAt: Date }
export type JoinRequest = { user: Person; createdAt: Date }

type GroupRow = {
  id: string
  slug: string
  name: string
  description: string | null
  privacy: GroupPrivacy
  _count: { members: number }
}

function toSummary(row: GroupRow): GroupSummary {
  return {
    id: row.id,
    slug: row.slug,
    name: row.name,
    description: row.description,
    privacy: row.privacy,
    memberCount: row._count.members,
  }
}

/** Every group the user belongs to, keyed by group id, with their role. */
export async function getMemberships(
  userId: string,
): Promise<Map<string, GroupRole>> {
  const rows = await prisma.groupMember.findMany({
    where: { userId },
    select: { groupId: true, role: true },
  })
  return new Map(rows.map((r) => [r.groupId, r.role]))
}

export async function getMemberGroupIds(userId: string): Promise<string[]> {
  return Array.from((await getMemberships(userId)).keys())
}

export async function getViewerRole(
  userId: string,
  groupId: string,

  viewerId: string,
  groupIds: string[],

      select: { groupId: true },
    }),

    requested: new Set(requests.map((r) => r.groupId)),
  }
}
```

```ts
import { revalidatePath } from 'next/cache'
import { redirect } from 'next/navigation'
import { z } from 'zod'
import { prisma } from '@/lib/db'
import { requireUser } from '@/lib/session'
import { deleteUpload } from '@/lib/storage'
import { fail, type ActionResult } from '@/lib/action-result'
import { groupSchema } from './schemas'
import { slugify, withSuffix } from './slug'
import {
  canChangeRole,
  canLeave,
  canManage,
  canRemoveMember,
  isGroupRole,
} from './permissions'
import { countAdmins, getViewerRole } from './queries'

function revalidateGroups() {
  // Membership and group settings affect the feed, group pages, the groups index and post cards.
  revalidatePath('/', 'layout')
}

function isUniqueViolation(e: unknown): boolean {
  return (e as { code?: string } | null)?.code === 'P2002'
}

function parseGroup(formData: FormData) {
  return groupSchema.safeParse({
    name: formData.get('name') ?? '',
    description: formData.get('description') ?? '',
    privacy: formData.get('privacy') ?? '',
  })
}

export async function createGroup(
  _prev: ActionResult,
  formData: FormData,
): Promise<ActionResult> {
  const user = await requireUser()
  const parsed = parseGroup(formData)
  if (!parsed.success) {
    return fail(
      'Please fix the highlighted fields',
      z.flattenError(parsed.error).fieldErrors,
    )
  }

  // First try the plain slug; on a collision retry a few times with a random suffix.
  const base = slugify(parsed.data.name)
  let slug: string | null = null
  for (let attempt = 0; attempt < 4 && !slug; attempt++) {
    const candidate = attempt === 0 ? base : withSuffix(base)
    try {
      await prisma.group.create({
        data: {
          ...parsed.data,
          slug: candidate,
          creatorId: user.id,
          members: { create: { userId: user.id, role: 'ADMIN' } },
        },
      })
      slug = candidate
    } catch (e) {
      if (!isUniqueViolation(e)) throw e
    }
  }
  if (!slug) return fail('Could not pick a unique address for this group; try another name')

  revalidateGroups()
  redirect(`/g/${slug}`)
}

export async function updateGroup(
  groupId: string,
  _prev: ActionResult,
  formData: FormData,
): Promise<ActionResult> {
  const user = await requireUser()
  if (!canManage(await getViewerRole(user.id, groupId)))
    return fail('Only admins can change group settings')

  const parsed = parseGroup(formData)
  if (!parsed.success) {
    return fail(
      'Please fix the highlighted fields',
      z.flattenError(parsed.error).fieldErrors,
    )
  }

  const slug = await prisma.$transaction(async (tx) => {
    const group = await tx.group.update({
      where: { id: groupId },
      data: parsed.data,
      select: { slug: true, privacy: true },
    })
    if (group.privacy === 'PUBLIC') {
      // A group that just became public has no gate: let everyone who was waiting in.
      const pending = await tx.groupJoinRequest.findMany({
        where: { groupId },
        select: { userId: true },
      })
      if (pending.length > 0) {
        await tx.groupMember.createMany({
          data: pending.map((p) => ({ groupId, userId: p.userId })),
          skipDuplicates: true,
        })
        await tx.groupJoinRequest.deleteMany({ where: { groupId } })
      }
    }
    return group.slug
  })

  revalidateGroups()
  redirect(`/g/${slug}`)
}

export async function deleteGroup(groupId: string): Promise<ActionResult> {
  const user = await requireUser()
  if (!canManage(await getViewerRole(user.id, groupId)))
    return fail('Only admins can delete a group')

  const images = await prisma.post.findMany({
    where: { groupId, imageUrl: { not: null } },
    select: { imageUrl: true },
  })
  // Row first, files second: a failed delete leaves no dangling image references.
  await prisma.group.delete({ where: { id: groupId } })
  for (const { imageUrl } of images) await deleteUpload(imageUrl)
  revalidateGroups()
  return { ok: true }
}

export async function joinGroup(groupId: string): Promise<ActionResult> {
  const user = await requireUser()
  const group = await prisma.group.findUnique({
    where: { id: groupId },
    select: { privacy: true },
  })
  if (!group) return fail('Group not found')
  if (await getViewerRole(user.id, groupId)) return { ok: true }

  // createMany + skipDuplicates: a double submit is a no-op, not an error.
  if (group.privacy === 'PUBLIC') {
    await prisma.groupMember.createMany({
      data: [{ groupId, userId: user.id }],
      skipDuplicates: true,
    })
  } else {
    await prisma.groupJoinRequest.createMany({
      data: [{ groupId, userId: user.id }],
      skipDuplicates: true,
    })
  }
  revalidateGroups()
  return { ok: true }
}

export async function respondToJoinRequest(
  groupId: string,
  userId: string,
  accept: boolean,
): Promise<ActionResult> {
  const user = await requireUser()
  if (!canManage(await getViewerRole(user.id, groupId)))
    return fail('Only admins can respond to join requests')

  const handled = await prisma.$transaction(async (tx) => {
    const { count } = await tx.groupJoinRequest.deleteMany({
      where: { groupId, userId },
    })
    if (count === 0) return false
    if (accept) {
      await tx.groupMember.createMany({
        data: [{ groupId, userId }],
        skipDuplicates: true,
      })
    }
    return true
  })
  if (!handled) return fail('That request was already handled')
  revalidateGroups()
  return { ok: true }
}

export async function leaveGroup(groupId: string): Promise<ActionResult> {
  const user = await requireUser()
  const role = await getViewerRole(user.id, groupId)
  if (!role) return fail('You are not a member of this group')
  if (!canLeave(role, await countAdmins(groupId)))
    return fail('Promote another admin before leaving')

  await prisma.groupMember.deleteMany({ where: { groupId, userId: user.id } })
  revalidateGroups()
  return { ok: true }
}

export async function removeMember(
  groupId: string,
  userId: string,
): Promise<ActionResult> {
  const user = await requireUser()
  const [actorRole, targetRole] = await Promise.all([
    getViewerRole(user.id, groupId),
    getViewerRole(userId, groupId),
  ])
  if (!actorRole) return fail('You are not a member of this group')
  if (!targetRole) return fail('That person is not a member')
  if (
    !canRemoveMember(
      { id: user.id, role: actorRole },
      { id: userId, role: targetRole },
    )
  )
    return fail('You cannot remove that member')

  await prisma.groupMember.deleteMany({ where: { groupId, userId } })
  revalidateGroups()
  return { ok: true }
}

export async function setMemberRole(
  groupId: string,
  userId: string,
  role: string,
): Promise<ActionResult> {
  const user = await requireUser()
  if (!isGroupRole(role)) return fail('Unknown role')
  const actorRole = await getViewerRole(user.id, groupId)
  if (!actorRole || !canChangeRole({ id: user.id, role: actorRole }, userId))
    return fail('You cannot change that role')

  const { count } = await prisma.groupMember.updateMany({
    where: { groupId, userId },
    data: { role },
  })
  if (count === 0) return fail('That person is not a member')
  revalidateGroups()
  return { ok: true }
}

// Form-action wrappers: <form action> expects a void-returning function. When the
// action fails (state changed under the user) re-render so the UI catches up.
function refreshOnFailure(result: ActionResult) {
  if (!result.ok) revalidateGroups()
}
export async function joinGroupForm(groupId: string): Promise<void> {
  refreshOnFailure(await joinGroup(groupId))
}
export async function cancelJoinRequestForm(groupId: string): Promise<void> {
  refreshOnFailure(await cancelJoinRequest(groupId))
}
export async function approveJoinRequestForm(
  groupId: string,
  userId: string,
): Promise<void> {
  refreshOnFailure(await respondToJoinRequest(groupId, userId, true))
}
export async function declineJoinRequestForm(
  groupId: string,
  userId: string,
): Promise<void> {
  refreshOnFailure(await respondToJoinRequest(groupId, userId, false))
}
export async function removeMemberForm(
  groupId: string,
  userId: string,
): Promise<void> {
  refreshOnFailure(await removeMember(groupId, userId))
}
export async function setMemberRoleForm(
  groupId: string,
  userId: string,
  formData: FormData,
): Promise<void> {
  const role = formData.get('role')
  refreshOnFailure(
    await setMemberRole(groupId, userId, typeof role === 'string' ? role : ''),
  )
}
export async function deleteGroupForm(groupId: string): Promise<void> {
  const result = await deleteGroup(groupId)
  refreshOnFailure(result)
  if (result.ok) redirect('/groups')
}
/** useActionState variant so the page can show "Promote another admin before leaving". */
export async function leaveGroupAction(
  groupId: string,
  _prev: ActionResult,
  _formData: FormData,
): Promise<ActionResult> {
  const result = await leaveGroup(groupId)
  if (result.ok) redirect('/groups')
  return result
```

```tsx
import { JoinRequestList } from '@/features/groups/components/JoinRequestList'
import { MemberList } from '@/features/groups/components/MemberList'
import { canManage } from '@/features/groups/permissions'
import {
  getGroupBySlug,
  getJoinRequests,
  getMembers,
} from '@/features/groups/queries'
import { requireUser } from '@/lib/session'

export const metadata: Metadata = { title: 'Members' }

export default async function GroupMembersPage({
  params,
}: PageProps<'/g/[slug]/members'>) {
  const viewer = await requireUser()
  const { slug } = await params
  const group = await getGroupBySlug(viewer.id, slug)
  if (!group) notFound()

  const showRequests = group.privacy === 'PRIVATE' && canManage(group.viewerRole)
  const [members, requests] = await Promise.all([
    getMembers(group.id),
    showRequests ? getJoinRequests(group.id) : Promise.resolve([]),
  ])

  return (
    <div className="flex flex-col gap-4">
      <h1 className="text-xl font-semibold">
        <Link href={`/g/${group.slug}`} className="hover:underline">
          {group.name}
        </Link>{' '}
        <span className="font-normal text-zinc-500">· Members</span>
      </h1>
      {showRequests ? (
        <JoinRequestList groupId={group.id} requests={requests} />
      ) : null}
      <MemberList
        groupId={group.id}
        members={members}
        viewer={{ id: viewer.id, role: group.viewerRole }}
      />
    </div>
  )
}
```

```ts
import { expect, test, type Browser, type Page } from '@playwright/test'
import { newUser, signUp, type TestUser } from './helpers'

async function userIn(
  browser: Browser,
  prefix: string,
): Promise<{ page: Page; user: TestUser }> {
  const context = await browser.newContext()
  const page = await context.newPage()
  const user = newUser(prefix)
  await signUp(page, user)
  return { page, user }
}

async function createGroup(
  page: Page,
  name: string,
  privacy: 'Public' | 'Private',
): Promise<string> {
  await page.goto('/groups/new')
  await page.getByLabel('Group name').fill(name)
  await page.getByLabel('Description').fill(`About ${name}`)
  await page.getByRole('radio', { name: privacy }).check()
  await page.getByRole('button', { name: 'Create group' }).click()
  await expect(page).toHaveURL(/\/g\/[a-z0-9-]+$/)
  await expect(page.getByRole('heading', { level: 1 })).toContainText(name)
  return page.url()
}

async function postIn(page: Page, body: string) {
  await page.getByLabel("What's on your mind?").fill(body)
  await page.getByRole('button', { name: 'Post' }).click()
  await expect(
    page.getByRole('article').filter({ hasText: body }),
  ).toHaveCount(1)
}

test('public group: create, join, post, and the post reaches both feeds', async ({
  browser,
}) => {
  const a = await userIn(browser, 'gpa')
  const b = await userIn(browser, 'gpb')
  const name = `Hikers ${Date.now()}`
  const url = await createGroup(a.page, name, 'Public')

  // It is listed under Your groups and findable by search
  await a.page.goto('/groups')
  await expect(
    a.page.getByRole('region', { name: 'Your groups' }),
  ).toContainText(name)
  await b.page.goto(`/groups?q=${encodeURIComponent(name.slice(0, 10))}`)
  const row = b.page.getByRole('listitem').filter({ hasText: name })
  await row.getByRole('button', { name: 'Join group' }).click()
  await expect(row).toContainText('Joined')

  // B posts in the group; A and B both see it in the group and in their feeds
  await b.page.goto(url)
  await expect(b.page.getByRole('button', { name: 'Leave group' })).toBeVisible()
  await postIn(b.page, 'Trail this Sunday?')
  for (const p of [a.page, b.page]) {
    await p.goto('/feed')
    const article = p.getByRole('article').filter({ hasText: 'Trail this Sunday?' })
    await expect(article).toHaveCount(1)
    await expect(article.getByRole('link', { name })).toBeVisible()
  }
  // A and B are not friends, so B's feed does not get A's timeline posts
  await a.page.goto('/feed')
  await postIn(a.page, 'Timeline only')
  await b.page.goto('/feed')
  await expect(b.page.getByText('Timeline only')).toHaveCount(0)
})

test('moderators can delete others’ posts; the last admin cannot leave', async ({
  browser,
}) => {
  const a = await userIn(browser, 'gma')
  const b = await userIn(browser, 'gmb')
  const name = `Mods ${Date.now()}`
  const url = await createGroup(a.page, name, 'Public')
  await b.page.goto(url)
  await b.page.getByRole('button', { name: 'Join group' }).click()
  await expect(b.page.getByRole('button', { name: 'Leave group' })).toBeVisible()

  await a.page.goto(url)
  await postIn(a.page, 'Admin says hi')

  // B is a plain member: no Delete on A's post
  await b.page.goto(url)
  const bView = b.page.getByRole('article').filter({ hasText: 'Admin says hi' })
  await expect(bView.getByRole('button', { name: 'Delete' })).toHaveCount(0)

  // A promotes B to moderator
  await a.page.goto(`${url}/members`)
  await a.page.getByLabel(`Role for ${b.user.name}`).selectOption('MODERATOR')
  await a.page
    .getByRole('listitem')
    .filter({ hasText: b.user.name })
    .getByRole('button', { name: 'Change role' })
    .click()
  await expect(
    a.page.getByRole('listitem').filter({ hasText: b.user.name }),
  ).toContainText('Moderator')

  // Now B can delete A's post
  await b.page.goto(url)
  await bView.getByRole('button', { name: 'Delete' }).click()
  await expect(bView).toHaveCount(0)

  // A is the only admin and may not leave
  await a.page.goto(url)
  await a.page.getByRole('button', { name: 'Leave group' }).click()
  await expect(
    a.page.getByText('Promote another admin before leaving'),
  ).toBeVisible()
  await expect(a.page).toHaveURL(url)
})

})
```
